# Nexora SMM — Pink Premium

Khmer + English responsive front-end demo for Nexora SMM.

## Files
- `index.html` — dashboard UI
- `style.css` — Pink Premium design
- `script.js` — language switcher and demo interactions
- `logo.svg` — Nexora SMM pink logo

## Run
Open `index.html` in a browser.

## GitHub Pages
Upload these files to the repository root, then enable **Settings → Pages → Deploy from a branch → main / root**.

> Demo only: real login, payments, provider connections, and persistent orders require a secure backend and database.
